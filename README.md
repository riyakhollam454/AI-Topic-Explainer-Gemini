# 🤖 AI Topic Explainer

AI Topic Explainer is a web-based educational application that uses Google's Gemini API to generate clear and structured explanations for any topic entered by the user.

The application is built using Python Flask with an HTML and CSS frontend. Users can select the explanation level and length and generate AI-powered educational content. The generated explanation can also be downloaded as a PDF or TXT file.

## 🚀 Features

- Generate explanations for any topic
- Beginner, Intermediate and Advanced explanation levels
- Short, Medium and Long explanation lengths
- AI-powered responses using Google Gemini API
- Clean and responsive web interface
- Download explanations as PDF
- Download explanations as TXT
- Error handling for API issues
- Secure API key management using `.env`

## 🛠️ Technologies Used

- Python
- Flask
- Google Gemini API
- Google GenAI Python SDK
- HTML5
- CSS3
- Python-dotenv
- ReportLab
